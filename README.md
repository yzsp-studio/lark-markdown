## 🇨🇳 中文

这是一个 Markdown 文件技能：查看、创建、上传、编辑和比较云端的原生 Markdown 文件。它特别覆盖「远端版本 vs 本地草稿」的对比场景，并推荐优先使用 shortcuts 走快速路径，文首给出快速决策指引。纯本地 Markdown 文件操作不会触发这个技能，它也不负责把 Markdown 导入成在线文档，更不管文件搜索、权限、评论、移动、删除等云空间管理操作。

### ✨ 能做什么

- 查看 / 创建 / 上传 / 编辑云端原生 Markdown 文件
- 比较远端版本与本地草稿，先看差异再动手
- 优先走 Shortcuts 快速路径，附快速决策表
- 纯本地 Markdown 操作不触发本技能，避免误用
- 明确排除导入在线文档与搜索、权限、评论、移动、删除

## 🇬🇧 English

A skill for native Markdown files in the cloud: view, create, upload, edit, and compare them. Its standout case is comparing the remote version against a local draft so you can see differences before pushing. Shortcuts are recommended as the fast path, and a quick-decision guide sits up front. Purely local Markdown editing does not trigger this skill. Importing Markdown as an online document is out of scope, as are file search, permissions, comments, moving, and deleting in cloud storage.

### ✨ What it does

- View, create, upload, and edit native cloud Markdown files
- Compare the remote version against a local draft before acting
- Prefers shortcuts as the fast path, with a quick-decision guide
- Purely local Markdown edits do not trigger it, avoiding misuse
- Excludes document import plus search, permissions, comments, moving, and deleting

### 📦 Skills included

- `lark-markdown` — [`lark-markdown/SKILL.md`](lark-markdown/SKILL.md)

### 🚀 Install

```bash
git clone https://github.com/yzsp-studio/lark-markdown.git
cp -r lark-markdown/* "$DSH_HOME/skills/"
```

> Skills are **plain-text instructions** (`SKILL.md` + `references/`). Zero dependencies, no API keys — they run on your agent's existing session quota.
